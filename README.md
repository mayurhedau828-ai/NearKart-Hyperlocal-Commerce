# NearKart - Hyperlocal Commerce Platform

NearKart is an AI-powered hyperlocal commerce platform that connects nearby customers with local retailers.

## Features

- Customer, Retailer & Admin Login
- Nearby Store Discovery
- AI Product Search
- Product Reservation
- Wishlist
- Inventory Management
- Retailer Dashboard
- Admin Panel

## Tech Stack

### Frontend
- React Native
- Expo
- Expo Router
- TypeScript

### Backend
- FastAPI
- MongoDB
- Motor

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --reload
```

### Frontend

```bash
cd frontend
npm install
npx expo start
```
